# GU4e1 owner checklist: 模组库 and 资源包/光影包

Use a local pack you can change (an empty local pack is best).

1. **Entry.** Right-click a pack on the 整合包 tab: the menu shows 模组 / 材质 / 光影 in one row and
   取消 fits inside the card.
2. **模组 list.** Search a name (Enter or the magnifier), scroll, 加载更多.
3. **模组详情.** 最新 card with 更新说明 and 前置; click a 前置 card, then back returns to the first mod.
   显示内测版, 显示其他版本, 打开百科 (opens MC百科).
4. **Install.** Click 安装 → dialog → 开始安装 → snackbar 查看任务 opens the task; the file ends as 已安装.
   Start the game, try another version of an installed mod: 运行中不可更新.
5. **Health.** Delete or edit the installed jar in `mods`, reopen the mod: 文件缺失 / 文件已被修改.
6. **材质 / 光影.** List, details, 显示Alpha, a gallery picture (复制链接, 浏览器打开), install a version.
7. **Room.** On a room you manage (local master): 模组 → 附加Mod opens the catalog for the room;
   install → 「已提交附加Mod添加任务，请在邮件中查看进度」. Shift+click 附加Mod opens the GitHub dialog.
8. **Compose afterwards.** Open the same pack's 模组 in Compose: the Slint-installed mod shows 已安装.
9. **1.7.10.** 模组 on a GTNH pack shows 「1.7.10 forge的整合包暂不支持模组库」.
