**Bug found and fixed:** `App::tick` returned before `refresh()` while the window was inactive (`paused`), so a list or tile change that arrived in the background was dropped for good. This also affected the old Kotlin `installedPacks.state` path. `refresh_pending` now keeps it until the window is active again. Not verified live: the MCP cannot make the window active.
